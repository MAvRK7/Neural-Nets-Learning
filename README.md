## Neural-Nets-Learning  
A repo documenting my learning journey through neural networks, inspired by Andrej Karpathy’s *Neural Networks: Zero to Hero* series.

### 📚 Learning Order

1. **NN — Basics of Neural Networks**  
   Intro to neural nets, manual gradient calculation, PyTorch intro, Micrograd  
   [Watch the video](https://www.youtube.com/watch?v=VMj-3S1tku0&list=PLAqhIrjkxbuWI23v9cThsA9GvCAUhRvKZ)

2. **Makemore — Character-level Name Generator (Bigram)**  
   Bigram model, 2D lookup tables, broadcasting, logits, counts, probabilities  
   [Watch the video](https://www.youtube.com/watch?v=PaCmpygFfXo&list=PLAqhIrjkxbuWI23v9cThsA9GvCAUhRvKZ&index=2)

3. **Makemore 2 — Bengio-style MLP**  
   Hidden layers, softmax, learning rate, vector embeddings  
   [Watch the video](https://www.youtube.com/watch?v=TCH_1BHY58I&list=PLAqhIrjkxbuWI23v9cThsA9GvCAUhRvKZ&index=3)

4. **Makemore 3 — Deeper Networks & Stability**  
   BatchNorm, `torch.Linear`, activation layers  
   [Watch the video](https://www.youtube.com/watch?v=P6sfmUTpUmc&list=PLAqhIrjkxbuWI23v9cThsA9GvCAUhRvKZ&index=4)

5. **BackPropPro — Full Manual Backprop**  
   End‑to‑end manual backpropagation  
   [Watch the video](https://www.youtube.com/watch?v=q8SA3rM6ckI&list=PLAqhIrjkxbuWI23v9cThsA9GvCAUhRvKZ&index=5)

6. **Makemore 5 — Wavenet-style Model**  
   Dilated convolutions, small ConvNets  
   [Watch the video](https://www.youtube.com/watch?v=t3YJ5hKiMQ0&list=PLAqhIrjkxbuWI23v9cThsA9GvCAUhRvKZ&index=6)

7. **GPT — Transformers & Mini Shakespeare**  
   Attention, shapes, class coding, small LLM finetuning  
   [Watch the video](https://www.youtube.com/watch?v=kCc8FmEb1nY&list=PLAqhIrjkxbuWI23v9cThsA9GvCAUhRvKZ&index=7)

8. **Tokenization — Unicode, Bytes, Regex, Tiktoken**  
   Encoding/decoding, tokenizer internals, importance of tokenization  
   [Watch the video](https://www.youtube.com/watch?v=zduSFxRajkE&list=PLAqhIrjkxbuWI23v9cThsA9GvCAUhRvKZ&index=9)

9. **GPT‑2 — Loading, Optimizing, Scaling**  
   Faster inference, approximations, FlashAttention, multi-core training (DDP), dataset improvements, “chat” mode  
   [Watch the video](https://www.youtube.com/watch?v=l8pRSuU81PU&list=PLAqhIrjkxbuWI23v9cThsA9GvCAUhRvKZ&index=10)
